# TimeNote PWA

휴대폰 브라우저에서 사용하는 설치형 웹앱입니다. 서버 없이 일정은 현재 브라우저의 localStorage에 저장됩니다.

## 컴퓨터 없이 배포하기: GitHub Pages
1. 휴대폰에서 GitHub에 로그인한 뒤 새 공개 저장소 `timenote`를 만듭니다.
2. 이 압축파일을 휴대폰의 파일 앱에서 풉니다.
3. GitHub 저장소에서 `Add file` → `Upload files`를 선택해 이 폴더의 **파일 5개(index.html, app.js, sw.js, manifest.webmanifest, icon.svg)**를 저장소 최상위에 업로드합니다. 휴대폰에서 버튼이 보이지 않으면 브라우저의 데스크톱 사이트 보기를 켜세요.
4. 저장소의 Settings → Pages → Build and deployment → Deploy from a branch를 선택하고 Branch를 `main`, 폴더를 `/ (root)`로 지정해 저장합니다.
5. 배포 후 `https://사용자명.github.io/timenote/` 주소를 열어보세요. Pages 활성화에는 시간이 걸릴 수 있습니다.
6. iPhone: Safari 공유 → 홈 화면에 추가. Android: Chrome 메뉴 → 홈 화면에 추가/앱 설치.

## 알림의 중요한 한계
- 현재 구현은 **앱 페이지가 실행 중일 때만** JavaScript 타이머가 일정을 확인하여 시스템 알림을 띄웁니다.
- 화면이 꺼지거나 앱이 종료되면 정확한 시각의 알림은 **보장되지 않습니다**. 서비스 워커 자체는 예약 알람 엔진이 아닙니다.
- iOS 웹 푸시는 홈 화면에 설치된 웹앱에서 지원되지만, 백그라운드 푸시를 위해서는 구독 관리, 푸시 서버, 예약 작업, 데이터 저장소가 별도로 필요합니다.
- `선택 날짜 일정 내보내기 (.ics)`로 기본 캘린더에 가져와 해당 앱의 알림 기능을 사용하는 것이 현재 현실적인 우회 방법입니다. 가져오기 및 알림 동작은 기기/캘린더 앱 설정에 따라 달라집니다.
- iOS에서는 무음 모드/집중 모드 제한이 적용될 수 있습니다.

## 데이터 주의
브라우저 저장소 삭제, 다른 브라우저 사용, 기기 변경 시 데이터가 자동 이전되지 않습니다. 이 앱은 서버 동기화 기능이 없습니다.
